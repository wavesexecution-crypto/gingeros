# Vidhi — a small game

A single-file, mobile-first interactive game made for Vidhi.

Tap through a collection of 14 observation cards — little things noticed and remembered — building toward one last message. Built with vanilla JS, HTML canvas particles, and the Motion animation library.

## Try it

Open `index.html` in a phone browser (or any browser — the game is designed for small screens).

## Customize

Everything personal lives in the `CARDS` array inside `index.html`:

- `prompt` — shown first
- `lines` — reveal lines
- `sub` — tiny footnote
- `memory` — optional memory paragraph
- `theme` — ambient glow color
- `gate` — shows a button first
- `secret` — hidden "..." note

## Deploy

It's a single static file — drop it on GitHub Pages, Vercel, Netlify, or any static host.
